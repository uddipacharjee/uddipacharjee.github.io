About

Most of what I build lives on the server: REST APIs on Spring Boot, batch jobs that load large flat files into PostgreSQL, and onboarding services that talk to other platforms through their management APIs.

I like code that stays easy to change: modules with clear boundaries, tests that run on every build, and services anyone on the team can start with a single docker compose up.

Modular services
Spring Boot applications split into modules with Spring Modulith, which talk to each other through domain events rather than direct calls.
Batch processing
Spring Batch jobs that load CSV and fixed-width files of up to a million rows into PostgreSQL, started on demand from a REST endpoint.
Integration APIs
Validated, OpenAPI-documented REST endpoints, including connector onboarding against Eclipse Dataspace Components.

Lately exploring Spring AI, retrieval-augmented generation, and MCP servers.
